Taller de CSS

En este taller pondrás en práctica los conceptos fundamentales de CSS mediante diferentes ejercicios de diseño y presentación de páginas web.

Cada ejercicio debe desarrollarse utilizando un archivo HTML y una hoja de estilos CSS independiente.

Organización de la entrega

Cada ejercicio debe desarrollarse en su propia carpeta. Dentro de cada carpeta deben existir el archivo HTML y su respectiva hoja de estilos CSS.

  • css/
    • ejercicio-1/
      • index.html
      • styles.css
    • ejercicio-2/
      • index.html
      • styles.css
    • ...
    • ejercicio-10/
      • index.html
      • styles.css

Importante: cada ejercicio debe utilizar únicamente los archivos correspondientes a su propia carpeta.

Ejercicios

Ejercicio 1 — Selectores CSS

Aplicar diferentes tipos de selectores CSS para modificar la apariencia de los elementos de una página.

Requisitos

  • Crear un título principal.
  • Crear tres párrafos.
  • Utilizar un selector por etiqueta.
  • Utilizar un selector por clase.
  • Utilizar un selector por id.
  • Aplicar diferentes colores y tamaños de texto a los elementos.

Conceptos

  • Selector por etiqueta.
  • Selector por clase.
  • Selector por id.

Ejercicio 2 — Colores y fondos

Personalizar la apariencia visual de una página utilizando colores, fondos y dimensiones.

Requisitos

  • Crear tres cajas.
  • Asignar un color diferente a cada caja.
  • Agregar color al texto.
  • Definir un fondo para la página.
  • Definir el ancho de las cajas.
  • Definir el alto de las cajas.

Conceptos

  • color
  • background-color
  • width
  • height

Ejercicio 3 — Tipografía

Diseñar visualmente una noticia utilizando diferentes propiedades relacionadas con la tipografía.

Requisitos

  • Crear un título principal.
  • Crear un subtítulo.
  • Crear dos párrafos.
  • Definir una familia tipográfica.
  • Modificar el tamaño del texto.
  • Modificar el peso de la fuente.
  • Modificar la alineación.
  • Transformar el texto.

Conceptos

  • font-family
  • font-size
  • font-weight
  • text-align
  • text-transform

Ejercicio 4 — Box Model

Crear una tarjeta personal y aplicar el modelo de cajas de CSS.

Requisitos

  • Mostrar el nombre.
  • Mostrar la carrera.
  • Mostrar la ciudad.
  • Agregar un borde.
  • Definir un espacio interno.
  • Definir un espacio externo.
  • Definir ancho y alto.

Conceptos

  • border
  • padding
  • margin
  • width
  • height

Ejercicio 5 — Display

Comprender cómo CSS modifica el comportamiento y la distribución de los elementos mediante la propiedad display.

Requisitos

  • Crear tres elementos div.
  • Crear tres elementos span.
  • Realizar pruebas utilizando block.
  • Realizar pruebas utilizando inline.
  • Realizar pruebas utilizando inline-block.
  • Realizar pruebas utilizando none.
  • Explicar las diferencias observadas.

Concepto

Propiedad display.

Ejercicio 6 — Flexbox

Crear un menú de navegación utilizando Flexbox para organizar sus elementos horizontalmente.

Requisitos

  • Inicio
  • Nosotros
  • Servicios
  • Contacto
  • Utilizar display: flex.
  • Definir la distribución de los elementos.
  • Definir la alineación.
  • Establecer separación entre los elementos.

Conceptos

  • display: flex
  • justify-content
  • align-items
  • gap

Ejercicio 7 — Grid

Crear una galería de productos utilizando CSS Grid para distribuir los elementos.

Requisitos

  • Crear seis productos.
  • Organizar los productos en tres columnas.
  • Agregar separación entre los elementos.

Conceptos

  • display: grid
  • grid-template-columns
  • gap

Ejercicio 8 — Responsive Design

Adaptar una página web para que pueda visualizarse correctamente en diferentes tamaños de pantalla.

Requisitos

  • Crear un contenedor principal.
  • Crear un encabezado.
  • Crear un área de contenido.
  • Utilizar un ancho definido para escritorio.
  • Adaptar el ancho del contenido para dispositivos móviles.

Conceptos

  • Media Queries.
  • @media (max-width: 768px)
  • Responsive Design.

Ejercicio 9 — Posicionamiento

Crear una página que permita experimentar con el posicionamiento de diferentes elementos utilizando CSS.

Requisitos

  • Crear un contenedor principal.
  • Crear varios elementos dentro del contenedor.
  • Utilizar diferentes tipos de posicionamiento.
  • Modificar la posición de los elementos utilizando las propiedades correspondientes.
  • Hacer que uno de los elementos se superponga sobre otro.

Conceptos

  • position
  • top
  • right
  • bottom
  • left
  • z-index

Ejercicio 10 — Pseudoclases

Crear una página con diferentes elementos interactivos y aplicar estilos dependiendo del estado o posición de cada elemento.

Requisitos

  • Crear un menú con varios enlaces.
  • Crear un formulario con al menos dos campos.
  • Crear una lista con varios elementos.
  • Aplicar un estilo diferente cuando el usuario pase el cursor sobre un elemento.
  • Aplicar un estilo diferente cuando un campo del formulario reciba el foco.
  • Aplicar estilos diferentes a determinados elementos de la lista según su posición.

Conceptos

  • :hover
  • :focus
  • :first-child
  • :nth-child()
