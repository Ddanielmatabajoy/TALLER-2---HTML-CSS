# 📚 Taller de Desarrollo Web - Biblioteca Virtual y Catálogo de Lenguajes

Proyecto desarrollado para la asignatura **Programación en Ambiente Web I**, como parte del taller práctico sobre HTML semántico, CSS y control de versiones con Git.

Este repositorio contiene **dos páginas web independientes** que comparten un mismo espacio de trabajo, demostrando el uso de buenas prácticas en desarrollo front-end y trabajo colaborativo.
---

##  Descripción

Este proyecto consiste en un sitio web estático que muestra un catálogo de lenguajes de programación destacados.  
Incluye información sobre cada lenguaje, su creador y una descripción general. También permite simular la adición de nuevos lenguajes mediante un formulario.

El diseño se basa en el sistema de estilos **classless de Pico CSS**, lo que permite una interfaz limpia, responsiva y accesible sin necesidad de escribir clases CSS pesadas.

---

##  Tecnologías utilizadas

- **HTML5** – Estructura semántica del contenido.
- **CSS3** – Estilos personalizados (variables, layout, animaciones).
- **Pico CSS (classless)** – Framework CSS ligero para estilos base y responsividad.
- **Git** – Control de versiones y trabajo colaborativo.

## Características principales

- ✅ **Diseño responsivo** con Pico CSS classless.
- ✅ **Grid de 3 columnas** para mostrar los lenguajes destacados.
- ✅ **Tarjetas interactivas** con efecto hover y borde coloreado por lenguaje.
- ✅ **Formulario** para agregar nuevos lenguajes (simulación visual).
- ✅ **Navegación interna** con enlaces a secciones.
- ✅ **Tema oscuro** personalizado mediante variables CSS.
- ✅ **Accesibilidad** básica con `:focus-visible` y etiquetas semánticas.
