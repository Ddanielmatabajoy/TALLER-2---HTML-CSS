Taller de HTML

En este taller pondrás en práctica los conceptos fundamentales de HTML mediante la construcción de diferentes páginas web. Cada ejercicio está diseñado para trabajar progresivamente los elementos y estructuras vistos durante el curso.

Desarrolla cada ejercicio utilizando HTML5 y aplica correctamente las etiquetas y estructuras solicitadas.

Estructura de entrega

Cada ejercicio debe desarrollarse en un archivo HTML independiente. Organiza los archivos de la siguiente manera:

  • HTML/
    • ejercicio-1.html
    • ejercicio-2.html
    • ejercicio-3.html
    • ejercicio-4.html
    • ejercicio-5.html
    • ejercicio-6.html
    • ejercicio-7.html
    • ejercicio-8.html
    • ejercicio-9.html
    • ejercicio-10.html

Importante: cada archivo debe contener únicamente el desarrollo del ejercicio correspondiente.

Ejercicios

Ejercicio 1 — Estructura básica HTML

Crear una página web que contenga información básica sobre el estudiante.

Requisitos

  1. Un título principal utilizando h1.
  2. Un párrafo con una presentación personal.
  3. Un segundo párrafo indicando la carrera que estudias.
  4. Una frase motivacional.

Ejercicio 2 — Texto y formato

Crear una página utilizando diferentes niveles de encabezados y etiquetas de formato de texto.

Requisitos

  1. Un h1 con tu nombre.
  2. Un h2 con tu carrera.
  3. Un h3 con tu ciudad.
  4. Un párrafo descriptivo.
  5. Un texto utilizando strong.
  6. Un texto utilizando em.
  7. Un texto utilizando mark.
  8. Un texto utilizando u.
  9. Un texto utilizando small.

Ejercicio 3 — Listas

Crear una página web que presente diferentes lenguajes de programación organizados de acuerdo con su área de desarrollo.

Requisitos

  • Agregar un título principal relacionado con el contenido.
  • Incluir un párrafo que describa brevemente los lenguajes de programación presentados.
  • Utilizar una lista para organizar las áreas de desarrollo.
  • Dentro de cada área, utilizar una lista anidada para presentar los lenguajes correspondientes.
  • Incluir dos áreas de desarrollo y tres lenguajes de programación en cada una.
  • Utilizar correctamente la estructura de listas anidadas.

Ejercicio 4 — Enlaces e imágenes

Crear una galería personal utilizando imágenes y enlaces externos.

Requisitos

  1. Incluir tres imágenes.
  2. Incluir tres enlaces externos.
  3. Agregar un título principal.
  4. Agregar una descripción para cada imagen.

Ejercicio 5 — Tablas

Crear una tabla que represente un horario académico.

Requisitos

  • Utilizar thead.
  • Utilizar tbody.
  • Utilizar tfoot.
  • Utilizar colspan.
  • Utilizar rowspan.

Información mínima

  • Día
  • Materia
  • Horario

Al finalizar la tabla se debe mostrar el total de materias.

Ejercicio 6 — Formularios básicos

Crear un formulario de registro utilizando los elementos básicos de los formularios HTML.

Campos requeridos

  • Nombre
  • Apellido
  • Correo
  • Contraseña

Agregar un botón para enviar el formulario.

Ejercicio 7 — Formularios avanzados

Crear un formulario de inscripción universitaria utilizando diferentes tipos de controles HTML.

Campos requeridos

  • Nombre
  • Correo
  • Edad
  • Fecha de nacimiento
  • Carrera utilizando select
  • Género utilizando botones radio
  • Habilidades utilizando checkbox
  • Foto utilizando file
  • Comentarios utilizando textarea

Ejercicio 8 — HTML semántico

Crear la estructura de un periódico digital utilizando las principales etiquetas semánticas de HTML5.

Elementos requeridos

  • header
  • nav
  • main
  • section
  • article
  • aside
  • footer

Agregar contenido de ejemplo dentro de cada sección.

Ejercicio 9 — Figuras y citas

Crear una página web sobre un personaje, escritor, científico, deportista o personaje histórico.

La página debe presentar información organizada mediante figuras, descripciones y citas.

Requisitos

  1. Un título principal con el nombre del personaje.
  2. Un párrafo introductorio sobre el personaje.
  3. Una imagen utilizando la etiqueta figure.
  4. Una descripción de la imagen utilizando figcaption.
  5. Una cita relacionada con el personaje utilizando blockquote.
  6. Una sección con información adicional sobre el personaje.
  7. Un enlace externo donde se pueda consultar más información.

Condiciones

  • Utilizar correctamente figure y figcaption.
  • Utilizar blockquote para representar una cita.
  • La imagen debe tener un texto alternativo mediante el atributo alt.
  • Organizar la información utilizando encabezados y párrafos.
  • El contenido debe ser elaborado por el estudiante.

Ejercicio 10 — Información desplegable

Crear una página web sobre una carrera universitaria utilizando elementos de contenido desplegable.

Requisitos

  1. Un título principal con el nombre de la carrera.
  2. Un párrafo con una descripción general de la carrera.
  3. Tres secciones de información desplegable utilizando details y summary.
  4. La primera sección debe presentar información sobre el perfil profesional.
  5. La segunda sección debe presentar información sobre las asignaturas o áreas de formación.
  6. La tercera sección debe presentar información sobre las oportunidades laborales.

Condiciones

  • Utilizar correctamente las etiquetas details y summary.
  • Cada sección desplegable debe contener información relacionada con la carrera.
  • Utilizar encabezados y párrafos para organizar el contenido.
  • El contenido debe ser elaborado por el estudiante.
